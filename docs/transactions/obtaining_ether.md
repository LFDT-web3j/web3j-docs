# Obtaining Ether

For development, use a [local development chain](../getting_started/run_node_locally.md) with test accounts or obtain Sepolia test ETH from the faucets listed in the [Ethereum network guide](https://ethereum.org/en/developers/docs/networks/#sepolia). Test ETH is for testing and has no monetary value.

Ethereum mainnet uses proof of stake; mining with a laptop or GPU is no longer a way to obtain mainnet ETH. For background on ETH and wallets, see [ethereum.org](https://ethereum.org/en/eth/).

Keep development credentials separate from accounts holding real funds. Confirm the chain ID and destination before sending a transaction.
