# Web3j {{ web3j.version }} API reference

Use the [core {{ web3j.version }} Javadoc](https://javadoc.io/doc/org.web3j/core/{{ web3j.version }}/index.html), generated from the artifact published to Maven Central.

For lower-level APIs, see the [crypto module](https://javadoc.io/doc/org.web3j/crypto/{{ web3j.version }}/index.html) and [ABI module](https://javadoc.io/doc/org.web3j/abi/{{ web3j.version }}/index.html).

The guide and API reference above target the same release. Select another published version on Javadoc.io when maintaining an older application. The old bundled 4.8.2-SNAPSHOT API is no longer served as the current reference.
